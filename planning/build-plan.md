# Build plan: Indiana County Civic Guide (St. Joseph County edition)

Design source: `planning/ux-review.md` (adopted, with Nick's overrides recorded in `Roadmap.md`). Data contract: `data/SCHEMA.md`.

## Architecture
- **Generator:** `tools/site/build.py` (Python stdlib only, no Jinja). Reads `data/indiana/*` + `data/editions/<county>/*` and writes static HTML into `site/<county>/`. Re-runnable, so a new edition = new data folder + `python -P -E tools/site/build.py --edition <county>`.
- **Hosting target 1:** private claude.ai Artifact, multi-file. Constraints that shape the build:
  - `index.html` is published as the page and gets wrapped in a skeleton, so the generator writes it WITHOUT doctype/html/head/body tags. Every other `.html` file IS a full document (with doctype, charset, viewport, its own `<title>`).
  - Shared `assets/style.css` + `assets/app.js` are published as files and linked relatively.
  - Only `#hash` routing (no query strings), so learning-path state is `#path-<id>-<n>`.
  - Viewers can't download files or print, so the /data page shows tables with copy-to-clipboard CSV.
  - Fonts only from Google Fonts. No external images: portraits ship as published files.
- **Hosting target 2 (later, needs Nick's explicit deploy trigger):** Netlify static. Same output, plus real CSV downloads and print stylesheet use.

## Visual identity (decided 2026-11-07)
- Series lockup "INDIANA COUNTY CIVIC GUIDE" + edition line "ST. JOSEPH COUNTY EDITION"; Indiana outline glyph (from `data/indiana/counties_svg.json`) with the edition county filled in the edition color.
- **Edition color:** teal (light `#0f766e`, dark `#2dd4bf`). Never red or blue.
- **Party colors are reserved for party data only, always with a text label:** D `#2a78d6`/`#3987e5`, R `#e34948`/`#e66767` (validated: CVD ΔE 21.6 light / 19.2 dark, all checks pass). Every other party is neutral gray + label.
- **Non-party charts** (budgets, demographics, turnout) use the edition teal or neutral ink. Never blue or red, so they don't read as partisan.
- **Type:** Public Sans (the US government's civic typeface) for body/UI; Big Shoulders Display (Chicago civic signage, regional) for display headings, used sparingly; IBM Plex Mono for figures, badges and form-like data (echoes the typed government forms).
- Status badges: OFFICIAL / UNOFFICIAL / COMPUTED / FROM SCAN / SECONDARY / SINGLE SOURCE, defined on /about/.
- Scope badges: INDIANA-WIDE (gray) / ST. JOSEPH COUNTY (edition teal) / ST. JOSEPH EXCEPTION.

## Charts (dataviz skill rules)
Inline SVG generated by Python, colored through CSS tokens (works in both themes, no chart library). 2px lines, 4px rounded bar ends at the baseline, hairline grid, direct labels selectively, hover tooltips via `app.js` (data attributes), a "Show table" toggle under every chart, one axis only, full available range by default.
